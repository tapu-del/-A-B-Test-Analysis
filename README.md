
# A/B Test Analysis

## Project Overview
Analyzed A/B test data to compare two versions (v1 and v2) based on click performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts

## What I Did
- Analyzed 300 rows of A/B test data
- Compared total clicks and average clicks per version
- Created Pivot Tables and Charts
- Wrote business insight

## Key Insights
- v1: 3714 total clicks (avg 53.83 per element)
- v2: 1587 total clicks (avg 27.36 per element)
- Conclusion: v1 performs better than v2
